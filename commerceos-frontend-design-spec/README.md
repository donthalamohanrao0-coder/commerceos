# CommerceOS Frontend Documentation

This directory is the frontend source of truth for the CommerceOS application.

## Documents

1. `01-design-system.md` — visual language and reusable UI rules
2. `02-customer-chat-interface.md` — AI shopping/chat experience
3. `03-merchant-dashboard.md` — merchant operations and revenue dashboard
4. `04-ai-agent-experience.md` — agent states, explainability, approvals and trust UX
5. `05-pages-and-user-flows.md` — page map and end-to-end user journeys
6. `06-frontend-architecture.md` — Next.js architecture and implementation conventions

## Implementation rule

Build against these documents rather than improvising page-by-page.

The customer chat is the hero experience. The merchant dashboard is the operational experience. Agent actions, money movement, approvals, and failures must always be understandable in the UI.
